# 卡利多歸航

這是獨立劇本模組，不會修改既有存檔。請在建立新遊戲時選擇「卡利多歸航：借來的名字」。

## 已實作內容

- 序幕、井邊白羽、南渡留言柱與第一章五段事件。
- 專屬 16:9 主選單背景：以金髮米莉拉主角取代原版中央人物；右側按鈕與左側訊息區保留安全留白。卸載本模組即恢復原版背景。
- 序幕主角會自動裝備「渡口長槍」：普通、耐候且可在鍛造台製作的地面武器，具有4.9格延伸刺擊，可被原版狩獵工作辨識；貼身時仍使用近戰工具。主線完成後只允許主角手中的一把渡口長槍進化成唯一神器「歸燈」。
- 第二至第六章共 19 項後續任務；戰鬥任務必須清除威脅，調查任務有實際準備時間，航標任務必須建成三座地面航標塔。
- 20 位固定姓名的米莉拉英雄（含伊蕾希雅），具有指定技能 20、主要熱情與獨立職能／戰鬥專精。
- 冒險者公會、鎖鏈商路、荒路強盜、白羽聖堂、蝕羽密教五個地面陣營；已安裝的美狐、奇羅、沃芬與萌螈會自動加入其生成池。
- 地面不存在米莉拉據點；米莉拉母城與玩家初始中立。蝕羽密教在第六章以前保持中立。
- 所有人類型襲擊（機械族、蟲族與實體除外）先開啟交涉；強盜條件更苛刻，鎖鏈商路可要求囚犯。
- 冒險者公會會定期收押殖民地囚犯並支付懸賞，不視為奴隸交易。
- 四類卡利多授權藍圖封鎖 63 個太空級米莉拉研究；普通冷兵器、工業級熱兵器與地面科技不受限制。
- 未取得武器／防具藍圖前，地面米莉拉無法用右鍵裝備、穿戴或由 AI 保留太空級裝備。
- 唯一神器「歸燈」具有獨立透明貼圖、不可製作、無耐久，只有米莉拉持有時會獲得完整共鳴。
- 墮天使復生：主角倒下時恢復傷勢並維持 60 秒；結束後依形態期間健康損失昏迷 1 至 7 天。
- 160 條四族隨機事件（每族 40 條），只在對應種族模組存在時抽取，選項會影響好感。
- 通用 NPC 16 格頭像，以及美狐、奇羅、沃芬、萌螈各 16 格女性頭像；對話會依說話者固定選格。
